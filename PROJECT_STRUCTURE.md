# Project Structure

## Files

- `index.html` - Main HTML structure
- `style.css` - Styles for the calculator interface
- `script.js` - JavaScript calculations and UI logic
- `README.md` - Project documentation
- `agents.md` - Agent definitions and project plan

## Folder Structure

```
breadyfrendy/
├── index.html
├── style.css
├── script.js
├── README.md
└── agents.md
```

## Development Approach

1. Start with basic HTML structure in `index.html`
2. Add CSS styling for mobile-friendly interface
3. Implement JavaScript calculations following the math specifications
4. Test all features including:
   - Baker's percentage calculations
   - Effective hydration calculations
   - Yeast conversions
   - Batch scaling
5. Optimize for kitchen use (mobile, clear display)
