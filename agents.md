# Agents

## Project Overview

This project is a web-based bread dough calculator that helps bakers determine precise ingredient amounts for various types of dough, including enriched doughs like brioche and challah.

## Agent Roles

### Math Agent
The Math Agent handles all the core mathematical calculations for the bread dough calculator:
- Baker's percentages calculation
- Effective hydration calculations (accounting for water content in eggs, milk, butter)
- Effective fat percentage calculations
- Yeast type conversions (instant, active dry, fresh)
- Flour absorption adjustments
- Batch scaling

### Frontend Agent
The Frontend Agent handles the web interface and user experience:
- HTML structure design
- CSS styling for mobile-friendly kitchen use
- JavaScript user input handling
- Real-time calculation updates
- Data visualization of results
- User interaction flow management

### Documentation Agent
The Documentation Agent maintains project documentation:
- README.md creation and maintenance
- Technical specification documentation
- Usage instructions
- Code comments and documentation
- Project status tracking and version control

## Defined Roles and Responsibilities

### Developer (Me)
- Implement all calculator functionality based on requirements
- Ensure educational content is properly integrated
- Create responsive, mobile-friendly interface
- Optimize performance and user experience
- Maintain code quality and consistency
- Debug any issues with mathematical calculations or UI flow
- Update documentation as needed during development process

### Project Manager (You)
- Review all implementation outputs for accuracy and completeness
- Provide feedback on requirements and functionality
- Approve final design and implementation decisions
- Define what "done" looks like for each feature iteration
- Control the scope of changes and ensure project stays aligned with goals
- Validate that all requirements (math, interface, education) are met

## Collaboration Process
1. Developer implements features based on requirements
2. Project Manager reviews output and provides feedback
3. Developer iterates based on feedback until Project Manager declares "DONE"
4. This process continues until final completion as defined by Project Manager

## Technologies Used

- HTML5
